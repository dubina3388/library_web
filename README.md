# library_web

Каталог библиотеки на Flutter Web: списки книг и авторов с поиском, фильтрами,
сортировкой, постраничным выводом, множественным и логическим удалением.
Состояние списка хранится в адресе страницы.

```
flutter pub get
flutter run -d edge --web-port=5566
flutter test
flutter analyze
```
